## ✨ Tentang SuperApp

**SuperApp** adalah platform web generasi baru yang menggabungkan fitur **Photo Booth Studio** bergaya *photostrip* fisik klasik dan **Generate Twibbon HD** interaktif ke dalam satu aplikasi berkelas.

Dirancang dengan prinsip desain *typography-first*, *clean minimalis*, serta mengutamakan kecepatan pemrosesan di sisi klien (*Client-Side Canvas Processing*), SuperApp memberikan pengalaman membuat foto kenangan dan kampanye visual berkualitas tinggi tanpa watermark, tanpa iklan mengganggu, dan tanpa batasan.

---

## 🚀 Fitur Unggulan

### 📷 1. Photo Booth Studio (Vertical Strip)

- 🎞 **Multi-Photo Strip Layout**:
  - Bebas memilih **2 Foto**, **3 Foto**, atau **4 Foto** vertikal dalam 1 bingkai photostrip fisik.
- ⏱ **Automated Countdown Photo Session**:
  - Sesi jepret otomatis dengan penghitung mundur (**3.. 2.. 1.. 📸 SNAP!**).
  - Jeda jeda pose 1.5 detik antar foto slot secara otomatis.
  - Efek animasi *screen flash* putih yang realistis saat jepretan dilakukan.
- 🖼 **6 Template Bingkai Arsitektural Vector**:
  1. **Airmail Minimalis**: Pattern garis tepi merah putih biru & tipografi clean.
  2. **Clean White Strip**: Bingkai putih tebal dengan header & caption bawah.
  3. **Staggered Layers**: Border offset 3D dengan aksen hijau primary (`#00DC82`).
  4. **Window Frame Gold**: Hitam doff elegan dengan garis emas mewah (`#C9A84C`).
  5. **Corner Accent**: Aksen sudut L-Shape emas & hijau di tiap slot foto.
  6. **Neon Cyber Strip**: Garis glowing neon hijau cyberpunk di sekeliling photo strip.
- 🎨 **8 Filter Efek Warna Studio (Canvas Shaders)**:
  - *B&W High Contrast*, *Sepia Vintage*, *High Contrast*, *Soft Matte*, *Film Grain*, *Vignette*, *Duotone Luxe (#00DC82 & #C9A84C)*, dan *Original*.
- ✏️ **Custom Header & Footer Text**:
  - Input kustom untuk Header Atas (contoh: `SMARTPEOPLE`), Sub-Header (contoh: `MORE SMART THAN PHONE`), dan Footer Bawah (contoh: `BACK TO OFFICE`).
- 📁 **Manajemen Slot Foto Individual**:
  - Pengguna dapat mengganti atau mengunggah gambar khusus untuk slot tertentu (#1, #2, #3, #4) secara manual.

---

### 🖼 2. Twibbon Generator HD

- 🎨 **Koleksi 8 Tema Twibbon Vector High-Res**:
  1. **Merdeka 79**: Pita Merah Putih, Lambang Garuda/Pita, & Slogan Nasional.
  2. **Elegant Gold**: Foil Emas Geometris & Lencana Keanggotaan Eksklusif.
  3. **Minimalist Black**: Potongan Hitam Putih Bold & Aksen Tag Hijau Primary.
  4. **Nature Bloom**: Ornamen Bunga Minimalis & Lengkungan Pastel Soft.
  5. **Geometric Pattern**: Shapes Geometris Diagional & Highlight Hijau Fresh.
  6. **Celebration**: Bintang, Konfeti, & Banner Perayaan Meriah.
  7. **Vintage Frame**: Border Klasik Filigree & Kartu Teks Retro.
  8. **Tech Future**: Overlay Cyber HUD Neon Cyan & Status Digital.
- 🎛 **Kontrol Interaktif Presisi Tinggi**:
  - ✋ **Drag & Reposition**: Geser foto secara bebas menggunakan mouse atau sentuhan (*touch move*).
  - 🔍 **Zoom Slider**: Atur ukuran foto dari 0.2x hingga 3.0x.
  - 🔄 **Rotasi Presisi**: Tombol rotasi cepat (0°, 90°, 180°, 270°).
  - 💧 **Opacity Slider**: Atur tingkat transparansi foto dari 10% hingga 100%.
- 💾 **Export & Share**:
  - Unduh hasil Twibbon dalam format PNG transparan atau bagikan link aplikasi secara instan.

---

### 🌙 3. Sistem Desain & Dark Mode

- 🌙 **Default Dark Mode**:
  - Aplikasi secara otomatis aktif dalam **Dark Mode** (`#0A0A0F`) dari sisi server (*SSR zero-flash*) untuk pengalaman visual yang mewah.
- ☀️ **Theme Switcher Smooth**:
  - Saklar mode gelap/terang di navbar kanan atas dengan animasi ikon yang mulus.
- 🚫 **Scrollbar Hidden**:
  - Garis scrollbar di sebelah kanan layar (baik pada tampilan mobile maupun wadah scroll preview) disembunyikan secara bersih tanpa mengurangi fungsi scroll (*smooth hidden scrolling*).
- 🧩 **100% Native Vector Icons**:
  - Seluruh ikon menggunakan komponen SVG `@lucide/vue` yang cepat, ringan, dan 100% responsif.

## 🛠 Teknologi Stack

| Komponen | Teknologi | Keterangan |
| :--- | :--- | :--- |
| **Framework Utama** | **Nuxt 3 / 4** | SSR & SSG Hybrid Framework berbasis Vue 3 |
| **Styling Engine** | **Tailwind CSS v4** | CSS Framework v4 dengan `@custom-variant dark` |
| **State Management** | **Pinia** | Store Reaktif untuk Photo Booth, Twibbon, & Tema |
| **Image Processing** | **HTML5 Canvas API** | Render pixel high-res, compositing, & shader filter |
| **Webcam Stream** | **WebRTC MediaDevices** | Mengakses kamera webcam & tangkap snapshot |
| **Tipografi** | **Plus Jakarta Sans** | Google Fonts typography hierarchy |
| **Icons Engine** | **@lucide/vue & Iconify** | Native SVG vector icons |
| **Utilities** | **@vueuse/core** | Helper composables & reactive utilities |

## 💻 Panduan Instalasi & Pengoperasian

### Prasyarat

Pastikan perangkat Anda telah terpasang:
- **Node.js**: `v18.0.0` atau versi lebih baru (Direkomendasikan `v20.x` / `v22.x`)
- **NPM** / **PNPM** / **Yarn** / **Bun**

### Langkah Instalasi

1. **Clone repositori proyek ini**:
   ```bash
   git clone https://github.com/4lifbima/superapp-nuxt.git
   cd Photobot
   ```

2. **Install seluruh dependencies**:
   ```bash
   npm install
   ```

### Menjalankan Server Pengembang

Jalankan server lokal pengembang di `http://localhost:3000`:
```bash
npm run dev
```

### Build Kompilasi Produksi

Untuk mengompilasi aplikasi ke versi produksi:
```bash
# Kompilasi build
npm run build

# Preview build produksi secara lokal
npm run preview
```
